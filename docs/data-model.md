# 当前数据模型

当前仓库以 `services/mock-db.js` 作为可执行的验收数据源。生产环境应由云函数或后端持久化相同的领域模型；小程序页面不得直接写入教务、存储或 ClassIn。

## 用户、身份与授权

| 集合/表 | 用途 |
| --- | --- |
| `users` | 以手机号为唯一识别，保存显示名、头像和状态。 |
| `userRoles` | 同一用户可拥有学生/家长、教师、管理员、教研等身份；会话明确保存当前身份。 |
| `adminGrants` | 超级管理员按年级和学科授予管理员范围；空范围配合 `fullAccess` 表示全机构。 |
| `sessions` | 当前 Mock 会话；生产端替换为受服务端校验的短期会话。 |

开发期保留 `phoneAccounts` 仅用于演示手机号兼容，不是生产账号模型。

## 教务只读镜像

| 集合/表 | 用途 |
| --- | --- |
| `students`、`teachers` | 从甲方报名/教务系统同步的基础档案。 |
| `courses`、`courseSessions` | 同步的课程与课次；课次保留外部 ClassIn 三元标识。 |
| 课程成员关系 | 由课程和课次中的 `studentIds` 表示；生产端以报名同步快照和增量事件维护。 |
| `auditLogs` | 管理员授权、资料发布、通关与同步处理的审计记录。 |

报名、插班、调班、退费、退班、排课和课程改名只在甲方教务系统写入。学习平台的公开教务写 API 必须返回 `READ_ONLY_ENROLLMENT`。

## 学习反馈与通关

| 集合/表 | 用途 |
| --- | --- |
| `lessonFeedbacks` | 课堂小测、本讲总结和内部通关确认；页面只显示前两类编辑入口。 |
| `wrongQuestionSelections` | 每个学生在某课次勾选的已发布资料单元、正确率和班级位置。 |
| `mediaFiles`、`files` | 图片、语音、反馈附件和教研原始资料的元数据；生产端保存私有存储键与临时访问地址。 |
| `studentAttentionNotes` | 管理员对重点关注或表现优秀学生的跟进备注。 |

通关率由已完成课次的确认通关记录动态计算，课程、教师和管理员看板复用同一统计口径。

## 教研资料库

| 集合/表 | 用途 |
| --- | --- |
| `materialPackages` | 年级、学科、学期、原始资料文件、版本和发布状态。 |
| `materialUnits` | 可勾选的题目单元；`group` 用于完整保留长阅读或综合题上下文。 |
| `materialPublishScopes` | 资料包可发布的年级、学科或平行班范围。 |
| `courseMaterialBindings` | 某课程/课次固定引用的已发布资料包版本，避免历史错题被修订覆盖。 |

教师端只读取已发布绑定资料；旧教师上传页不注册为小程序路由。

## ClassIn 与生产迁移

每个课次以 `classInCourseId`、`classInTeacherId`、`classInSessionId` 唯一定位 ClassIn，不按物理教室配置。服务端在确认报名关系和管理员范围后签发不超过 10 分钟的入口；任何密钥不得进入小程序源码。

生产迁移前必须具备：微信手机号授权映射、教务快照/事件接口、CloudBase 或后端权限、私有对象存储、ClassIn 签名服务，以及真实 PDF/Word 生成服务。详细输入输出见 `docs/integrations/`。
