# 趣帆学习空间 小程序视觉验收清单

目标：用微信开发者工具真实预览当前主流程页面，确认小程序符合“浅纸感管理风”，没有退回旧的暗色 Demo 页、普通后台模板或工程占位界面。

## 必验页面

1. 登录页：`pages/login/login`
2. 学生/家长首页：`pages/parent/home/home`
3. 学生/家长课表：`pages/parent/courses/courses`
4. 课堂小测：`pages/parent/quiz/quiz`
5. 本讲总结：`pages/parent/summary/summary`
6. 错题本与导出：`pages/parent/exercises/exercises`
7. 老师首页：`pages/teacher/home/home`
8. 老师课程表：`pages/teacher/courses/courses`
9. 老师学生名单：`pages/teacher/feedback-students/feedback-students`
10. 老师反馈详情：`pages/teacher/feedback-detail/feedback-detail`
11. 管理首页：`pages/admin/home/home`
12. 管理员授权：`pages/admin/manage/manage`
13. 直播入口：`pages/live-player/live-player`

## 全局视觉

- 页面应呈现浅纸感、低噪声、管理工具式的信息层级。
- 主色应围绕 `#E9E6DA`、`#FFFDF6`、`#10224A`，不能退回深色森林首屏或蓝紫渐变。
- 页面不应出现大块营销式 hero、装饰性渐变圆球、无业务含义的图形。
- 卡片只用于独立信息项、表单面板和重复列表项，不能出现 `qf-card` 嵌套。
- 图标优先使用 `assets/icons/*.svg`，主流程页面不使用 emoji 或粗糙符号代替图标。

## 业务页面重点

- 登录页只展示正式手机号登录和低强调“快速体验”，不出现 LOGO 占位、调试说明或演示账号大块面板。
- 一个手机号拥有多个身份时，登录页应出现身份选择；个人页应仅在多身份时显示紧凑的身份切换列表。
- 学生/家长首页必须优先看到下一次上课时间、课次、任课教师和地点；完整排课只在课表页查看。
- 课堂小测和本讲总结必须进入各自对应内容；横向课次导航要显示前后按钮、页码和分页状态。
- 本讲总结详情按图片、文字评语、文档、语音条顺序直接展示，不要求家长二次点击才能理解内容。
- 错题本导出卡片必须在内容区首位，PDF/Word 按钮清晰，不能挤在标题区。
- 老师课程表使用头像/图标和短按钮，按钮文案使用“课堂小测 / 总结错题 / 本讲总结”，不回到“课前错题 / 课后错题”。
- 老师反馈详情必须能看到文字、图片、文档、语音、错题勾选、正确率/班级位置、确认通关。
- 管理端必须展示年级、学科、教师通关率和重点关注学员；不出现插班、调班、退班、教室合集或全校课表操作入口。
- 管理员授权页只允许超级管理员按手机号配置年级和学科范围；分级管理员底部导航不显示“授权”。

## 移动端布局

- 375px 宽度模拟器下文字不能挤出卡片或按钮。
- 自定义底部导航不遮挡页面最后一块内容。
- 搜索、筛选、导出、确认通关等操作按钮点击态不能出现默认灰块。
- 长列表页面必须保留搜索或滚动容器，不能靠超长卡片堆叠。

## 自动化门禁

- `node scripts/check-js.js` 必须通过。
- `node scripts/smoke-test.js` 必须通过。
- 微信开发者工具 `preview` 必须成功生成预览码。
- smoke 已覆盖旧品牌/旧主流程文案、页面层 emoji、卡片嵌套、错题本导出位置和老师端旧按钮文案。

## 失败判定

出现以下任一情况，不算完成：

- 页面仍注册旧壳页面作为主入口。
- 页面出现调试账号、mock 占位、插班/调班/退班或教室直播配置等演示外露文案。
- 主流程仍使用“课前测 / 课后测 / 课堂总结”等旧命名。
- 反馈详情仍需要反复点开才能看到图片、评语、语音。
- 微信开发者工具有编译错误或预览失败。
- 仅代码和 smoke 通过，但没有真机或模拟器逐页截图确认。
